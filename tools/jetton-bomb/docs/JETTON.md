# Jetton Spam

## Предварительно

0. Зависимости: `yarn`
1. Настроить эндпоинт API в `blueprint.config.ts`
2. Сделать `export WALLET_MNEMONIC=`, `export WALLET_VERSION=` как обычно для блюпринта

## 1. Деплой кошельков

```bash
# Сгенерировать мнемонику и задеплоить 1000 кошельков
COUNT=1000 NEW=1 yarn blueprint run --mnemonic deployWalletSpam
```

Параметры (env):
- `COUNT` -- количество кошельков
- `NEW` -- сгенерировать новую мнемонику (иначе возьмет из `mnemonic.txt` если есть)

Скрипт:
- Деплоит 0-й кошелек
- Отправляет reproduce -- 0-й кошелек рекурсивно деплоит остальные
- Мнемоника сохраняется в `mnemonic.txt`

## 2. Запуск спама

```bash
# 10 отправок/сек
COUNT=1000 FREQ=10 yarn blueprint run --mnemonic jettonSpam
```

Параметры (env):
- `COUNT` -- количество задеплоенных кошельков (обязательно)
- `FREQ` -- частота отправок в секунду
- `PERIOD` -- период между отправками в мс

Скрипт бесконечно выбирает рандомный кошелек из диапазона 0..COUNT-1 и отправляет jetton transfer на случайный адрес. Мнемоника читается из `mnemonic.txt`.
